## 🛠️ Requirements

* Python 3
* Tkinter

### Install Tkinter

```bash
pip install tkinter
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ABX532/XGTodo.git
cd XGTodo
```

### 2. Run XGTodo

```bash
python3 main.py
```

That's it. No complicated setup required.
